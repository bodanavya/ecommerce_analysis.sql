Project Title: E-Commerce Sales Data Analysis using SQL

Project Description:
This project focuses on analyzing an e-commerce dataset using SQL to extract meaningful insights from sales and customer data. SQL queries were used for data cleaning, filtering, aggregation, and analysis to understand customer behavior, sales trends, product performance, and business patterns.

Objectives:

Clean and preprocess the dataset using SQL

Perform exploratory data analysis (EDA)

Analyze sales performance and customer behavior

Identify top-selling products and order trends

Generate insights using SQL queries


SQL Concepts Used:

SELECT, WHERE, ORDER BY

GROUP BY, HAVING

Aggregate functions (SUM, AVG, COUNT)

Filtering and sorting data

Data cleaning operations
